## 依頼内容
todoをdbから削除するapiを実装してください

## 目的
TODOを削除機能実装のため

## 前提
- アーキテクチャ : Java + Spring boot + H2DB
- 対象ファイル : TodoController.java
- 既存テスト : TodoControllerTest.java

## 仕様
- リクエストの`P_KEY`を用いて当該レコードの削除を行う
- 処理成功時はレスポンスのコード値`200`を返却し、呼び出し側はそれをもとに判断する
- DBアクセスエラーが発生した場合は、処理を中断し、レスポンスにエラーコードを設定して返却する

## 受入条件
- 既存のテスト全件パス
- 新規テストの追加
- `mvn install`の成功

## 禁止事項
- 無関係の既存ファイル更新は禁止
- 新しいライブラリの依存性追加禁止

## 終了条件
- DDLに整合性問題が出た場合は作業を中断する
- 既存テストが原因不明で失敗し続ける場合は、原因を調査して中断する
