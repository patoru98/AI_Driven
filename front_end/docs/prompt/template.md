## 依頼内容
エントリーフォームへ氏名を追加してください

## 目的
氏名を扱えるようにするため

## 前提
- アーキテクチャ : Java + Spring boot + H2DB
- 対象ファイル : XXX.java(表にまとめて一覧で見れるようにしてもいいかも？)
- 既存テスト : XXXTest.java

## 仕様
- エントリーテーブルへ氏名(VARCHAR(10))を追加
- APIのリクエスト、レスポンスに氏名を追加
- 検索対象に氏名を追加

## 受入条件
- 既存のテスト全件パス
- 新規テストの追加
- mvn installの成功

## 禁止事項
- エントリー機能以外のファイル変更禁止
- 新しいライブラリの依存性追加禁止

## 終了条件
- カラム追加で既存データやDDLに整合性問題が出た場合は作業を中断する
- 既存テストが原因不明で失敗し続ける場合は、原因を調査して中断する
